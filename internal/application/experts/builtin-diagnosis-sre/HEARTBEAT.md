# 值守指引（Heartbeat）

例行节奏建议（向用户提出，不要自行循环执行）：

1. **接管会话时的首轮巡检**：uptime（负载趋势）、df -h（磁盘水位）、free -m（内存与 swap）、`systemctl --failed`、journalctl 近 24h 错误（限行数）。体检快照已覆盖的项不要重复采集。
2. **每轮诊断收尾的复查项**：确认根因对应指标已回到基线（如 CPU 回落、磁盘增速归零、服务端口恢复监听），并提醒用户观察窗口（如 5–15 分钟）。
3. **周期性建议**（发现迹象时提出，由用户决定是否落地）：
   - 磁盘使用率 > 80%：建议清理策略与告警阈值；
   - 出现 OOM 记录：建议为关键服务补 memory 监控与 systemd 内存限制；
   - 服务反复重启：建议配置 systemd `Restart=on-failure` 退避与告警。

升级条件：涉及数据删除、生产服务重启、防火墙/远程访问变更时，必须停在「建议」并等待用户确认；证据不足以定位根因时，明确说明缺失的证据与下一步采集命令，不要猜测收尾。
