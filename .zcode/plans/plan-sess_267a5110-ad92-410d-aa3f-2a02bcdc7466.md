# 本地终端会话（跨平台，不走 SSH）

已确认：Windows 默认 shell 用 PowerShell 优先探测（pwsh → powershell → cmd）；本地会话的 Agent 启用但仅限本机工具（local_exec/local_read_file），SFTP 禁用。macOS/Linux 用 $SHELL 探测。

## 后端

### 1. 依赖
`go get github.com/aymanbagabas/go-pty`——纯 Go（无 CGO，符合项目约束），Unix 走 openpty、Windows 走 ConPTY。网络失败时用 `GOPROXY=https://goproxy.cn,direct` 重试。

### 2. 新包 `internal/infrastructure/localpty/manager.go`
镜像 ssh.Manager 的会话生命周期（uuid 会话表 + mutex），但面向本机 PTY：
- `Open(cols, rows int, events application.SessionEvents) (sessionID, error)`：
  - sessionID = `local-` + uuid（前缀是 TerminalService 的路由依据）
  - `pty.New()` → `Resize(cols, rows)`；shell 探测：windows 依次 `exec.LookPath("pwsh.exe")` → `"powershell.exe"` → `COMSPEC`/`cmd.exe`；darwin/linux 用 `$SHELL` → `/bin/zsh`、`/bin/bash`
  - `cmd := pty.Command(shell)`；`cmd.Dir` = 用户主目录；Unix 下 `cmd.Env` 附加 `TERM=xterm-256color`；`Start()`
  - goroutine 泵输出 → `events.OnData(sessionID, chunk)`；goroutine `Wait()` → `events.OnExit(sessionID, err)` 并清理会话表（复用 term:<id>:out/:exit 事件契约，前端零改动）
- `WriteStdin / Resize / Close / CloseAll` + `ErrSessionNotFound`；`IsLocal(id)` 前缀判断导出

### 3. `interfaces/terminal_service.go` 路由 + 新方法
- 新方法 `OpenLocalSession(size PtySizeDTO) (OpenSessionResult, error)`（事件流复用 terminalEvents）
- `WriteStdin / ResizeSession / CloseSession`：`localpty.IsLocal(id)` → localMgr，否则 connManager；`ServiceShutdown` 关闭两个 manager
- `NewTerminalService` 增加 localMgr 参数（main.go 同步装配）

### 4. Agent 支持本地会话（仅本机工具）
- `tools/tools.go` 增加 `BuildLocalForSession(sessionID)`：只构建 `local_exec` + `local_read_file`（带 observe 包装，工具事件照常）
- `runtime.go` Chat 内按 `strings.HasPrefix(sessionID, "local-")` 分流：本地用 BuildLocalForSession + 本地版 system prompt（说明只可用本机工具、注意审批语义）；SSH 路径不变。CredsResolver 本地不触及；多轮记忆/审批门控天然复用

### 5. `wails3 generate bindings -ts` 重新生成绑定（新增 OpenLocalSession）

## 前端

### 6. `terminal.store.ts`
- 新 action `addLocalSession(id, name)`（内部 hostID 传空，`hostID === ""` 即本地会话的判定，加注释说明）

### 7. `hosts/hooks.ts`
- 新 mutation `useOpenLocalTerminal`：`TerminalService.OpenLocalSession({cols:80, rows:24})` → `addLocalSession(sessionId, t?名称由调用方传)`——名称在组件层用 locale 文案传入

### 8. `TerminalView.tsx`
- **标签栏尾部 "+" 按钮**：点击打开本地终端（浏览器式新标签体验）
- 空状态增加"打开本地终端"次按钮
- `duplicateSession / reconnectSession`：本地会话分支走 openLocal mutation
- 工具栏：SFTP 按钮 `disabled` + 提示"需要 SSH 主机"；Agent 按钮本地会话可用
- 右键菜单"编辑主机"项：本地会话 disabled
- 标签图标：本地会话用 Monitor 图标（osInfo 查不到时的 Server fallback 不适用本地）
- 复制地址按钮本地天然禁用（activeHost 为空，现有逻辑）

### 9. locale（en/zh 同步）
`terminal.localTab`（"Local"/"本地"）、`terminal.newLocalTab`、`terminal.openLocal`、`terminal.sftpNeedsHost`

### 10. 验证
`go build/test` + 绑定 + `tsc` + `npm run build` + locale 键核对；`wails3 dev` 手测：开本地终端出 PowerShell、交互/颜色/resize、关闭标签清理、本地会话 Agent 只见本机工具

## 风险
- go-pty `Resize(width, height)` 的宽高语义（实施时从库源码核对，避免与 ssh.WindowChange(rows, cols) 的顺序混淆）
- ConPTY 对某些老 Windows 构建（<1809）不可用——报错信息会正常透传到 UI
- go get 网络问题用 goproxy.cn 兜底
