# 主机编辑对话框 Xshell 式分组改造

已确认：纯每主机配置（移除全局终端字体设置）、顶部标签页、三组划分（连接/外观/组织）。

---

## 1. HostFormDialog 重构为顶部标签页（核心）

`frontend/src/features/hosts/HostFormDialog.tsx`：

- 对话框从三栏布局（max-w-4xl）改为**顶部标签页 + 单栏表单**（max-w-2xl）
- 标签栏：仿照 SettingsView 分类导航和终端 Tab 的现有模式——原生 button + `role="tablist"/"tab"` + `aria-selected` + cn() 激活态，不引入新依赖（项目未装 Radix Tabs）
- tab 状态：`useState<"connection" | "appearance" | "organisation">`，默认"connection"

**Tab 1 · 连接**（合并现第 1、3 栏）：
- OS 只读指示条（编辑时）、名称、主机、用户名、端口、认证方式、私钥路径（保存值）
- 凭据区：密码 / 密钥覆盖 + 密码短语 / ssh-agent 提示（按认证方式切换）、"记住密码"复选框、测试结果 Badge
- 原三栏的分区标题（"连接/组织/凭据"图标小标题）随分组取消，tab 即分组

**Tab 2 · 外观**（新增重点）：
- 终端配色方案：下拉（默认项文案改为"默认"）+ 现有 3 色圆点预览
- 终端字体：直接下拉（"Cascadia Mono（默认）"等，移除上轮的"覆盖"复选框——纯每主机无需覆盖语义；选"默认"= 清空字段）
- 终端字号：滑杆 10–22（字段为 0 时显示默认 13；拖动即写入实际值，回到 13 等价默认）
- 新增小型实时预览条：用所选主题背景色 + `terminalFontFamily()` + 字号渲染一行示例命令（`user@host:~$ …`），即时看到组合效果（复用 TERMINAL_THEMES 与 fonts.ts，无新逻辑）

**Tab 3 · 组织**：
- 分组下拉 + 自定义分组输入（保持现有的条件显示逻辑）
- 标签 chips + TagInput

**校验联动**：name/host/username/port 全在连接 tab——校验失败时自动 `setTab("connection")` 再展示行内错误，避免错误藏在未激活 tab 里。

底部按钮（删除 | 测试 / 连接并打开 / 保存）与防重复提交逻辑不变。

## 2. 移除全局终端字体设置（纯每主机）

- `frontend/src/features/settings/SettingsView.tsx`：删除"终端字体"卡片（字体下拉/字号滑杆/预览条）及 TERMINAL_FONTS、terminalFontFamily 引用；DEFAULT_CONFIG 去掉 terminalFont/terminalFontSize；移除 useSetAppConfig 调用
- `frontend/src/features/settings/useAppConfig.ts`：删除文件（TerminalPanel 不再读全局配置后无任何使用方）
- `frontend/src/features/terminal/TerminalPanel.tsx`：字体解析改为纯主机值——`terminalFontFamily(session.terminalFont || "")`、`session.terminalFontSize || 13`；删除 useAppConfig 依赖（热更新 effect 与 fit 逻辑保留）
- `frontend/src/features/terminal/fonts.ts`：保留（HostFormDialog 与预览共用）
