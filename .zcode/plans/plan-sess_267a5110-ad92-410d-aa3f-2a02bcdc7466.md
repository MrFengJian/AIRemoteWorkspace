# Xshell 式工作区合并：主机侧栏 + 终端标签区

已确认：Xshell 式合并布局；侧栏承载主机管理全功能，独立主机页移除。会话标签保留在终端区顶部（参考工具共识）。

## 目标布局

```
┌─┬─────────────┬──────────────────────────┐
│图│ 🔍 搜索 + 添加 │ [web-1●][db-1●][本地●][+]│
│标├─────────────┼──────────────────────────┤
│栏│ ▾ 生产环境(2) │                          │
```

点击主机即开标签（有活跃会话则激活），全程无页面跳转。

## 改动清单

### 1. 新组件 `features/hosts/HostsSidebar.tsx`（核心）
- **数据**：`useHosts()`（沿用 React Query）+ `useTerminalStore` sessions（在线状态）
- **顶部**：搜索框（复用现有 name/host/username/group/tags 联合过滤）+ 添加主机小按钮
- **分组折叠列表**：沿用现有排序（production→stage→test→自定义→未分组），组头 Folder 图标+名称+计数，折叠状态本地 state 默认展开
- **主机项**：OS 图标（osInfo，fallback Server）+ 名称 + `user@host` 小字 + **会话状态点**（按 hostID 聚合最新会话状态着色，复用标签栏四色语义）；hover 显示 连接/编辑/删除 小按钮（照搬 HostsView 行操作，含 focus-within 可达性）
- **交互**：单击 = 有活跃会话则激活其标签，无则连接；连接失败回落到编辑对话框（移植 HostsView.handleConnect 逻辑，不再 setView——已在终端）
- **右键菜单**：新开标签（强制新会话）/ 编辑 / 删除（复用 TerminalTabMenu 通用菜单组件 + 现有确认弹窗）
- **底部**：＋本地终端（useOpenLocalTerminal）、＋添加主机
- **空状态**：无主机时侧栏内提示 + 添加按钮

### 2. TerminalView 布局改造
- 根结构改 `flex`：左侧 `<HostsSidebar />`（w-60 固定，border-r）+ 右侧现有全部结构（标签栏/工具栏/终端区/右面板）不变
- 空状态简化：侧栏常在后不再需要引导跳转，改为一行居中提示（指向侧栏主机/本地终端），删除 goToHosts 按钮
- 标签栏尾部 "+"（本地终端）保留——与侧栏入口并存无害

### 3. HostsView.tsx 删除
- `HostFormDialog` 挂载迁至 AppShell（本就由全局 useHostsUIStore.editing 驱动，对话框全局覆盖无碍）
- HostFormDialog 的"连接并打开"成功后 `setView("terminal")` 移除（已在终端工作区）

### 4. 导航层
- `ui.store`：AppView = `"terminal" | "settings"`，默认视图改 `"terminal"`（启动即工作区）
- `Sidebar`：移除主机项，剩 终端/设置 两项
- `AppShell`：移除 HostsView 的 View 块

### 5. locale（en/zh）
- 新增：`hosts.newTab`（新标签打开）、`hosts.sidebarEmpty`（侧栏空状态）、`terminal.emptyHint`（工作区空提示，指向侧栏）
- 删除：`hosts.title/subtitle/noHostsTitle/noHostsDesc/addFirst/doubleClickHint/doubleClickTitle`、`nav.hosts`、`terminal.goToHosts`
- 保留：searchPlaceholder（侧栏复用）、authType.*、分组/删除确认等
