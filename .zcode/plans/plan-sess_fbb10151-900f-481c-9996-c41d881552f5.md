# Phase 3 — 文件管理（SFTP）实施计划

## 决策（用户已确认）
1. **基础文件操作**：ls/cd/下载/上传/删除/重命名。不做双面板拖拽/递归目录传输/进度条。
2. **按 host 缓存 SFTP 连接**：建立后缓存，空闲 10 分钟自动关闭。与终端连接独立。

## 技术选型
- **SFTP 库**：`github.com/pkg/sftp`（社区标准，基于 `golang.org/x/crypto/ssh`，无 CGO）。
- 复用现有 `ssh.Dial`（Phase 2）建立连接，`ssh.Client` 暴露底层 `*ssh.Client` 给 SFTP。
- **大文件传输**：SFTP 流式读写，不一次性加载到内存；通过 Wails 事件发进度（本次基础版可省略，下载/上传用临时文件中转）。

## 文件传输策略（基础版）
- **下载**：SFTP 远程文件 → 本地临时文件 → 用 Wails 的文件保存对话框选目标位置 → 移动临时文件。或更简单：前端调 `DownloadFile(hostID, remotePath)` 返回数据 → 前端用 Blob 触发浏览器下载。**采用后者**（Wails webview 支持标准 Blob 下载，简单且无需临时文件管理）。
- **上传**：前端 `<input type=file>` 选文件 → 读为 ArrayBuffer → 传给后端 `UploadFile(hostID, remotePath, data)` → SFTP 写入。受限于内存（单文件），MVP 足够。

## 执行步骤

### Step 1 — 后端 SFTP 基础设施（infrastructure/sftp）
新增 `internal/infrastructure/sftp/`：
- `manager.go`：`Manager` 持有按 hostID 缓存的 `*sftp.Client`（+ 对应 `*ssh.Client`），空闲 10 分钟自动关闭。`Close()` 清理。
- 依赖注入 `ssh.HostKeyStore` 和 dial 函数（复用 `ssh.Dial`）。
- 方法：`Client(host, creds) → *sftp.Client`（按 hostID 缓存，若已有则复用，否则拨号+建 SFTP client+缓存）。

### Step 2 — 后端 SSH Client 暴露 + SFTP 操作（infrastructure）
- `ssh/client.go`：加 `SSHClient() *ssh.Client` 导出方法（供 sftp.NewClient 用）。
- `sftp/operations.go`：封装文件操作：
  - `ListDir(host, creds, path) → []Entry{name, size, mode, modTime, isDir}`
  - `Stat(host, creds, path) → Entry`
  - `DownloadFile(host, creds, path) → []byte`（基础版整文件读，限制大小如 50MB）
  - `UploadFile(host, creds, path, data []byte) → error`
  - `DeleteFile(host, creds, path) → error`
  - `RenameFile(host, creds, oldPath, newPath) → error`
  - `Mkdir(host, creds, path) → error`

### Step 3 — application 层 SftpService
- `internal/application/sftp_service.go`：`SftpService` 组合 sftp.Manager + HostService（用于 ResolveCredentials）。方法对应 Step 2 的操作，接受 hostID 自动解析凭据（复用 Phase 5 的 ResolveCredentials）。

### Step 4 — Wails SftpService（interfaces）
- `internal/interfaces/sftp_service.go`：`SftpService` 暴露给前端：
  - `ListDir(hostID, path) → []FileEntryDTO`
  - `DownloadFile(hostID, path) → []byte`
  - `UploadFile(hostID, path, data) → error`
  - `DeleteFile(hostID, path) → error`
  - `RenameFile(hostID, oldPath, newPath) → error`
  - `Mkdir(hostID, path) → error`
- DTO：`FileEntryDTO{name, size, mode, modTime, isDir}`。
- `main.go`：组装 SftpManager + SftpService + 注册 Wails Service。

### Step 5 — 前端 SFTP feature（features/sftp）
- `api.ts`：封装生成的 SftpService 绑定 + `FileEntryDTO` 类型。
- `store.ts`：当前 host 选择、当前路径、文件列表、加载状态。
- `SftpView.tsx`：文件浏览器 UI：
  - 顶部：host 选择器（从 Hosts 列表选）+ 路径栏（面包屑/输入）+ 刷新/上传/新建文件夹按钮
  - 文件列表：名称、大小、修改时间、类型图标（Folder/File，lucide）
  - 行操作：下载、重命名、删除（右键菜单或行内按钮）
  - 双击文件夹进入，双击文件下载
  - 空态/加载态/错误态

## 风险与缓解
- **大文件内存**：基础版整文件读写，限制 50MB。超限返回明确错误，提示用专用 SFTP 客户端。后续可改流式+分块事件。
- **SFTP 连接缓存失效**：网络断开导致缓存连接失效。检测到错误时清理缓存条目，下次操作重连。
- **权限错误**：SFTP 操作可能因权限失败。错误信息透传到 UI，不吞没。
- **测试服务器**：真实 SFTP 联调需用户提供服务器；代码路径确保无误。
