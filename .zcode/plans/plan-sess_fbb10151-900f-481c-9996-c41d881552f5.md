## 执行步骤

### Step 1 — 用 `react` 模板脚手架（在 `F:\work\RemoteWork` 内）
- `wails3 init -n ai-remote-workspace -t react -git github.com/ai-remote/workspace -productname "AI Remote Workspace" -productidentifier com.airemote.workspace`
- CLI 会在当前目录创建 `ai-remote-workspace/` 子目录。**然后将其内容上移到仓库根**（与现有 `AGENT.md`/`README.md`/`docs/` 同级），删除空壳目录。
- 删除模板自带的 `greetservice.go`，保留 `main.go`、`Taskfile.yml`、`build/`、`frontend/`、`go.mod`、`.gitignore`。

### Step 2 — 升级到 React 19 + 叠加 AGENT.md 前端栈
在 `frontend/` 下：
- `package.json`：`react`/`react-dom` → `^19`，`@types/react`/`@types/react-dom` → `^19`，加 `@types/node`。
- 安装 Tailwind v4（`tailwindcss @tailwindcss/vite`，Vite 插件模式，匹配模板的 Vite 8）+ `clsx` `tailwind-merge`（shadcn 依赖）。
- 安装 Radix UI primitives（按 shadcn 需要逐个加，先装 `@radix-ui/react-slot` `react` 实用包）+ `lucide-react`。
- 安装 `zustand`、`@tanstack/react-query`。
- shadcn/ui：用 `npx shadcn@latest init` 初始化（React 19 已支持），先加 `button` `card` 等基础组件。
- `vite.config.ts`：加 `@tailwindcss/vite` 插件 + `resolve.alias` `@ -> ./src`。
- `tsconfig.json`：加 `paths` `@/*` + `noUnusedLocals` 保留（匹配 AGENT.md "TypeScript strict"）。
- `index.html`：移除模板的 `<link rel="stylesheet" href="/style.css">`，标题改 "AI Remote Workspace"。
- 清空模板的 `src/App.tsx`（crossfade demo）和 `public/style.css`。

### Step 3 — 前端 Design System（Dark Developer Theme）
按 AGENT.md §5 的 Design Token 架构：
- `src/styles/globals.css`：Tailwind v4 `@import "tailwindcss"` + `@theme` 块定义 token（`--background`、`--foreground`、`--primary`、`--border`、`--radius`、`--shadow`），暗色配色对标 VS Code Dark / Cursor Dark。
- `src/lib/utils.ts`：`cn()` helper（`clsx` + `tailwind-merge`）。
- `src/components/ui/`：shadcn 组件目录。

### Step 4 — 前端 Feature-Based 骨架（AGENT.md §6）
建立目录占位 + 最小可见内容：
```
frontend/src/
  app/
    providers/   (QueryProvider, ThemeProvider)
    router/      (后续 Phase 用)
  features/
    hosts/       (components/, store.ts, api.ts 占位)
    terminal/    (TerminalView.tsx 占位)
    agent/       (AgentPanel.tsx, ToolCall.tsx 占位)
    sftp/        (占位)
    settings/    (占位)
  components/
    ui/          (shadcn)
    layout/      (AppShell, Sidebar, TopBar, StatusBar)
  stores/        (全局 store)
  lib/           (utils, queryClient)
  themes/        (dark/ token 集合)
  main.tsx       (挂载 providers + AppShell)
```
`AppShell` 实现：左侧 Sidebar（Hosts / Terminal / SFTP / Agent / Settings 图标导航，Lucide 图标）、主内容区（Phase 1 显示欢迎/空态）、底部 StatusBar（显示 Wails 版本、时钟——复用模板的 time event）。键盘驱动与 Command Palette 留到后续 Phase（AGENT.md §4 列为目标但 Phase 1 仅"基础布局"）。

### Step 5 — 前后端通信打通（验证绑定 + Events）
- `main.go`：移除 GreetService，注册两个真实 Service：
  - `SystemService`（`SystemInfo()` 返回 app 版本/平台/go 版本）—— 为后续 MCP `system_info` 与 StatusBar 铺路。
  - `ConfigService`（GetAppConfig/SetAppConfig，结构含 securityMode 等）—— 对应 TODO "配置管理"。
- 前端 `features/settings/api.ts` 调用生成的 `bindings/.../ConfigService`，验证调用链。
- 保留模板的 `time` event（StatusBar 显示），作为 Events 打通的证明。

### Step 6 — 后端分层骨架（AGENT.md §7）+ SQLite
```
internal/
  domain/         (host.go, session.go, tool.go, agent.go 类型定义)
  application/    (connect_host.go, execute_tool.go, run_agent.go 接口)
  infrastructure/ (sqlite/ 存储实现, secret/ SecretStore 接口, llm/ 占位)
  interfaces/     (wails services 调用 application 层)
```
- SQLite：用 `modernc.org/sqlite`（**纯 Go，无 CGO**——契合 AGENT.md §8.1 "不默认 SQLCipher，避免 CGO" 和 §1 "单 Binary"）。
- `internal/infrastructure/sqlite/`：连接管理、schema 迁移（`schema.sql` 含 `hosts`、`sessions`、`settings` 表，`hosts` 表含 `secret_ref` 列对应 §9）。
- 应用启动时初始化 DB（放在用户数据目录，用 `github.com/adrg/xdg`，该依赖模板已传递引入）。

### Step 7 — 验证构建（dev + production）
- `wails3 task dev`：开发模式热重载，确认窗口启动、前端渲染、Service 调用、StatusBar 时钟、SQLite 初始化。
- `wails3 task build`：产出 `bin/ai-remote-workspace.exe`（单 Binary，验证 §19 "单 Binary"）。
- 不跑完整 GUI 自动化测试（环境限制），通过 dev 模式启动成功 + build 产出二进制作为 Phase 1 验收。

### Step 8 — 文档同步
更新 `README.md`（Vue3→React19 技术栈）、`docs/ARCHITECTURE.md`、`docs/PRD.md` 技术栈段、`docs/TODO.md`（勾选 Phase 1 完成项）、`docs/ROADMAP.md`（Phase 1 标记完成），消除 Vue3/React 不一致。

## 风险与缓解
- **React 19 + shadcn 兼容**：shadcn 已官方支持 React 19；若 `shadcn init` 因 Wails 的 `frontend/` 非根目录失败，改手动放置组件文件（shadcn 本质是复制源码）。
- **Tailwind v4 + Vite 8**：v4 用 `@tailwindcss/vite` 插件而非 PostCSS 配置，配置方式与旧教程不同——按 v4 官方方式。
- **Wails v3 beta API**：若 dev 模式或某个 API 在本机环境异常，停下报告而非硬编码 workaround。
