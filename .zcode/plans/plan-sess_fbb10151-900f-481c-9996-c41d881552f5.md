# 设置页面全面重构计划

## 概述
将设置页面从简单的 4 卡片列表重构为分类式桌面应用设置页，同时实现真正的主题切换、字体配置、语言下拉等能力。

## 分类结构
```
设置
├── 外观 (Appearance)
│   ├── 主题模式：浅色 / 深色 / 跟随系统（单选）
│   ├── 界面字体（下拉 + 预览）
│   ├── 中文字体（下拉，单独设置 CJK 渲染）
│   └── 字体大小（滑块/输入，12-18px）
├── 语言 (Language)
│   └── 界面语言（下拉：简体中文 / English）
├── 终端 (Terminal)  ← 仅默认值说明 + 跳转提示
│   └── 提示"终端配色方案已移至主机配置，可在会话右键菜单中动态切换"
├── 高级 (Advanced)  ← 原运行时 + 安全
│   ├── 安全模式（显示当前值）
│   ├── 默认 Shell
│   └── LLM 配置入口
└── 关于 (About)
    └── 应用版本 / 平台 / Go 版本（只读）
```

## 执行步骤

### Step 1 — 主题系统实现（light/dark/follow）
**globals.css**：
- 保留现有 `@theme` 块作为 **dark** 默认值
- 新增 `:root[data-theme="light"]` 覆盖块，定义浅色 token（白色背景、深色文字、浅色边框等）
- `data-theme="dark"` 显式标记深色（与无属性时一致）
- `data-theme="auto"` 通过 `@media (prefers-color-scheme: light)` 响应系统
- `body` 的 `font-family` / `font-size` 改为 CSS 变量 `--app-font` / `--app-font-size` / `--cjk-font`

**AppConfig 扩展**（后端）：
- `Theme` 字段语义改为 "light" | "dark" | "auto"（默认 "dark"）
- 新增 `UIFont string`（界面字体名）、`FontSize int`（px）、`CJKFont string`（中文字体）

**前端主题切换**：
- 新建 `ThemeProvider`：读取 AppConfig 的 theme 值，设置 `<html data-theme="...">`
- 语言/字体变化时更新 CSS 变量 + `document.documentElement.style`

### Step 2 — 字体配置
- 界面字体下拉：列出常见无衬线字体（Inter / Segoe UI / system-ui / SF Pro / Microsoft YaHei / 自定义输入）
- 中文字体下拉：列出常见 CJK 字体（Microsoft YaHei / PingFang SC / Noto Sans CJK / Source Han Sans）
- 字体大小：12-18px 数字输入或滑块
- 所有字体设置通过 CSS 变量 `--app-font` / `--cjk-font` / `--app-font-size` 应用到 body
- 保存到 AppConfig（新增字段），启动时恢复

### Step 3 — 语言切换改为下拉
- 从两个按钮改为 `<select>` 下拉
- 保持 i18next 的 `changeLanguage` + localStorage 持久化

### Step 4 — 终端配色方案迁移
**从全局设置移除**：
- SettingsView 删除"终端配色方案"卡片
- 全局 `terminalTheme` 保留在 AppConfig 作为**默认值**（新 host 无指定时用此），但不在设置页编辑

**会话右键动态切换**：
- TerminalPanel 右键菜单加"终端配色方案"子菜单（列出 6 个方案）
- 选中后即时更新当前 pane 的 xterm theme（不持久化到 host，仅当前会话生效）

**HostFormDialog 保留**：
- 主机编辑对话框的终端配色选择器保留（持久化到 per-host）

### Step 5 — 设置页面美化
- 左侧分类导航（Appearance / Language / Terminal / Advanced / About）
- 右侧内容区，选中分类高亮
- 每个设置项有标签 + 描述 + 控件的标准行布局
- 使用现有 Card 组件但更紧凑
- 底部状态栏保留

### Step 6 — 后端字段 + 绑定 + 翻译 + 构建
- AppConfig 加 UIFont/FontSize/CJKFont 字段 + GORM 迁移
- config_service 兜底默认值
- 绑定重新生成
- 翻译条目（新分类标题 + 字段描述）
- 构建验证

## 不在本次范围
- 字体文件打包（继续依赖系统字体，仅提供字体名选择）
- 自定义主题导入/导出
- 终端字体的单独设置（终端字体保持硬编码等宽字体）
- 设置项的实时预览面板（如 VS Code 那样的预览窗口）
