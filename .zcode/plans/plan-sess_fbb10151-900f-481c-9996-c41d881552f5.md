# 主机操作系统自动识别 + 图标展示

## 需求
1. Host 连接成功后自动检测操作系统信息（若尚无），存入 Host
2. OS 信息**只读展示**，用户不可编辑
3. 按常见发行版关联图标，从外部下载 SVG 使用

## 已验证（技术依据）
- **simple-icons CDN 可用**（jsDelivr）：`ubuntu/rockylinux/windows/apple/alpinelinux` 等均返回 200
- **接入点**：`ssh.Manager.ExecInSession(sessionID, cmd)` 可在已有连接上执行一次性命令（无需重新认证）
- **存储**：`domain.Host` + GORM `hostModel` 加 `OS` 列，AutoMigrate 自动迁移
- **前端展示**：`HostsView.tsx` HostRow 的 `flex items-center gap-2` 行（auth-type/group badge 旁）加 OS badge；`public/` 是现有静态资源机制（favicon.png 先例）

## 执行步骤

### Step 1 — 下载 OS 图标 SVG（frontend/public/os/）
- 从 jsDelivr `simple-icons` 下载常用发行版图标，存入 `frontend/public/os/<id>.svg`：
  - **Linux 家族**：ubuntu, debian, centos, rockylinux, almalinux, fedora, archlinux, opensuse, alpinelinux, redhat, kalilinux, linuxmint, manjaro, elementaryos, freebsd
  - **Windows / macOS**：windows, apple
  - **通用 fallback**：linux（simple-icons 的 `linux` 图标）
- 每个下载后验证非空且含 `<svg`
- 下载脚本用 curl，逐个处理失败（记录缺失即可，不阻断）

### Step 2 — 后端：OS 检测 + 存储
- `domain.Host` 加 `OS string`（`hostModel` 加列，AutoMigrate 自动迁移）
- `infrastructure/ssh/`：加 `DetectOS(sessionID) (string, error)`——用 `ExecInSession` 跑 `cat /etc/os-release`，解析 `NAME=`/`ID=` 字段，返回发行版 id（小写，如 `ubuntu`）；未知返回 `linux` 泛型兜底
- `application/host_service.go`：加 `EnsureOS(hostID, sessionID)`——若 host.OS 为空，检测并 Save；只在连接时调用
- **只读保证**：`CreateHostInput`/`HostInputDTO` **不包含** OS 字段（用户不可编辑），只有 `HostDTO` 输出含 `os`

### Step 3 — 后端：连接时触发
- `TerminalService.OpenSession` 成功后，后台 goroutine 调 `EnsureOS`（不阻塞连接、失败静默——检测失败不影响终端使用）
- 也可在 `TestConnection` 成功后触发（顺带填充 OS）

### Step 4 — 前端：OS 展示（只读）
- `HostsView.tsx` HostRow：host 名旁加 OS badge——`<img src="/os/<os>.svg">` + 名称（`osName` 映射表显示友好名，如 ubuntu→Ubuntu）
- 图标映射表 `osIcons.ts`：id → { svgPath, displayName, fallback: "linux" }
- `HostFormDialog` Connection 列加一行只读 OS 展示（若有）
- 绑定重新生成后 `HostDTO.os` 自动可用

### Step 5 — 验证 + 文档
- `wails3 task build` 通过、启动验证
- 更新 docs/TODO（OS 识别不属于现有 Phase，作为增强记录在 README 状态）
- 测试：连接 host → host 列表显示 OS 图标+名称；无 OS 的 host 在连接后自动填充

## 关键设计
- **自动触发**：连接成功即检测，无需手动操作
- **只读**：OS 字段不在任何编辑输入中暴露，仅展示
- **图标降级**：未知发行版 → `linux` 泛型图标；`os` 为空 → 不显示 badge
- **失败静默**：OS 检测失败不影响连接和终端使用

## 不在范围
- OS 版本号详情（如 "22.04 LTS"）——本版只存发行版 id
- 手动触发重新检测（后续可加右键菜单项）
- 图标的自定义/上传
