# Phase 5 — 安全增强（SecretStore）实施计划

## 目标
实现"记住密码"功能:SSH 密码/密钥 passphrase 存入**操作系统密码库**(非 SQLite),让用户不必每次连接重新输入。优先 Windows,然后 macOS、Linux。

## 技术选型（已通过源码研究确认,全部无 CGO）

| 平台 | 库 | 机制 | CGO |
|---|---|---|---|
| Windows | `github.com/danieljoos/wincred v1.2.3` | syscall → advapi32.dll CredWriteW/CredReadW | ❌ 无 |
| macOS | `github.com/zalando/go-keyring v0.2.8` | exec `/usr/bin/security` | ❌ 无 |
| Linux | `github.com/zalando/go-keyring v0.2.8` (含 godbus/dbus/v5) | Secret Service D-Bus | ❌ 无 |

三者均支持 `CGO_ENABLED=0`,单 Binary 约束不变。Windows 用 wincred(`[]byte` blob 直接匹配);mac/linux 共用 go-keyring(string API,适配层转换)。

## 关键决策

1. **存什么**:SSH 密码、密钥 passphrase。**不存私钥文件内容**(私钥在磁盘上,只存路径)。API Key/Token 留给后续(AI Agent Phase 4 用)。
2. **secret_ref 命名**:`airemote:host:<hostID>:<kind>`,kind ∈ {password, passphrase}。存入 SQLite `hosts.secret_ref`(逗号分隔多个,或单值优先)。读时按 kind 查 keychain。
3. **Security Mode** (AGENT.md §10):本次实现 **Balanced(默认)** 行为——提供"记住"勾选框,勾选则存 keychain;不勾则仅内存。Convenience/Secure 模式切换作为 ConfigService 扩展项,但不强制阻断 Phase 5 核心功能。
4. **删除 Host 时级联删除 keychain 条目**:避免残留孤儿凭据。

## 执行步骤

### Step 1 — SecretStore 抽象与实现（infrastructure/secret）
- `internal/infrastructure/secret/secret.go`:定义 `Store` 接口 `Set(key string, value []byte) error` / `Get(key) ([]byte, error)` / `Delete(key) error` + `ErrNotFound`。定义 `Default()` 返回当前平台实现。
- `secret_windows.go` (`//go:build windows`):用 wincred。`NewGenericCredential(key).CredentialBlob = value; Write()`;`GetGenericCredential` 读 `CredentialBlob`;`Delete()`。`wincred.ErrElementNotFound` → `ErrNotFound`。
- `secret_darwin.go` (`//go:build darwin`):用 go-keyring。service="AI Remote Workspace", user=key。string↔[]byte 转换。`keyring.ErrNotFound` → `ErrNotFound`。
- `secret_linux.go` (`//go:build linux`):同 darwin(go-keyring Linux 后端)。
- `secret_unsupported.go` (`//go:build !windows && !darwin && !linux`):返回 `ErrUnsupported`,方法 no-op。

### Step 2 — application 层 SecretService
- `internal/application/secret_service.go`:`SecretService` 封装 `secret.Store`,提供 `SaveHostSecret(hostID, kind, value)` / `GetHostSecret(hostID, kind)` / `DeleteHostSecrets(hostID)`。key 用 `airemote:host:<id>:<kind>` 格式。
- 注入到 `HostService`:删除 Host 时调 `DeleteHostSecrets(hostID)` 清理 keychain。

### Step 3 — Host 凭据流贯通（后端 interfaces）
- 扩展 `HostService`(Wails):
  - `SaveCredentials(hostID, creds CredentialsDTO, remember bool)`:remember=true 时,把 password/passphrase 存 keychain,secret_ref 写回 SQLite;remember=false 时清理 keychain 条目(若存在)。
  - `GetRememberedCredentials(hostID)`:返回是否有已存凭据 + 填充 password/passphrase(不含 key 内容)。
  - 修改 `OpenSession`/`TestConnection`:如果传入 creds 为空,自动尝试从 keychain 取回。
- `main.go`:组装 `secret.Default()` → `SecretService`,注入 HostService/TerminalService。

### Step 4 — 前端"记住密码"UI
- `HostFormDialog`:凭据区加"记住密码/记住 passphrase"勾选框(`@radix-ui/react-checkbox` 或原生 input)。
- 打开编辑对话框时,调 `GetRememberedCredentials(hostID)`:若有已存凭据,显示"已保存"状态 + 勾选框默认勾选;密码字段不回显(安全),显示占位符。
- "Test"/"Connect" 时,把 remember 状态连同 creds 传给后端 `SaveCredentials`。
- 新增 `features/settings/SecurityView.tsx`:显示当前 Security Mode(只读,后续可扩展切换)。

### Step 5 — shadcn Checkbox 组件 + 删除级联
- 新增 `components/ui/checkbox.tsx`(@radix-ui/react-checkbox)。
- `HostService.Delete` 时确保级联清理 keychain(Step 2 已处理,验证)。

### Step 6 — 验证 + 文档
- `wails3 task build` 通过(Windows,验证 wincred 集成)。
- 启动 binary:添加 Host → 输入密码 → 勾选记住 → 连接 → 关闭 → 重新编辑该 Host → 确认"已保存"状态 → 不输密码直接连接成功 → 删除 Host 确认 keychain 清理。
- Windows Credential Manager 验证:用 PowerShell `cmdkey /list` 或控制面板查看凭据。

## 风险与缓解
- **wincred 2560 字节限制**:SSH 密码/passphrase 远低于此,无影响。研究已确认。
- **macOS go-keyring 用 /usr/bin/security 子进程**:每次调用 fork 进程,略慢但可接受(连接时一次性操作)。无 CGO 是关键优势。
- **Linux 无 D-Bus 环境**(如最小服务器):go-keyring 会报错。UI 显示"凭据存储不可用"降级提示,不阻断密码内存使用。
- **测试限制**:Windows Credential Manager 可在本机验证;mac/linux 实现按相同接口编写但因平台 build tag 在 Windows 上不编译,需在对应平台验证(代码会通过编译期 build tag 隔离保证正确)。
